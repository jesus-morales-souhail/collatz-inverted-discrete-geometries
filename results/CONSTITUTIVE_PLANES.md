# Constitutive product on discrete planes

Fourier: $q=-k\nabla T$. Ohm: $J=\sigma E=-\sigma\nabla V$.

On a 1D grid the gradient is convolution with $d$. With constant $\kappa$
and a circular embedding the DFT gives


F\{\mathrm{flux}\}_k=-\kappa H_k F\{u\}_k.


The cell line carries fields $\varphi^E$, $\varphi^S$, $\varphi^H$ and the
base index. Each admits the same flux form. The maps $f$ and $g$ build
the potentials; they are not linear Ohm/Fourier laws.
